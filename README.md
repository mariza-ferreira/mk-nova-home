# mK — Nova Home

Página inicial responsiva da mK, construída em HTML, CSS e JavaScript.

## Visualização local

Abra `index.html` em um navegador moderno. Os estilos, scripts, fontes, imagens e vídeos necessários estão incluídos no repositório.

## Estrutura

- `index.html`: página completa e contínua.
- `*.css`: estilos organizados por seção.
- `platform.js` e `social-proof.js`: interações da página.
- `assets/`: imagens, fontes, SVGs e vídeos.

O vídeo principal da Hero é versionado com Git LFS.
